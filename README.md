# جوال يوسف الضايع — حملة «ثلاثة على كيفك» من ڤاليلا

موقع ثابت (HTML + CSS + JS) بدون أي سيرفر أو بناء. يشتغل مباشرة على GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودع جديد على GitHub (مثلاً `valila-lost-phone`) واجعله Public.
2. ارفع **محتوى هذا المجلد** (مو المجلد نفسه) إلى جذر المستودع:
   `index.html` و`styles.css` و`app.js` و`.nojekyll` ومجلد `assets`.
3. من المستودع: Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يصير الرابط: `https://اسم-حسابك.github.io/valila-lost-phone/`

## قبل ما تنشر الرابط على تويتر

صورة المشاركة (`assets/img/share.jpg`) لازم يكون رابطها كامل عشان تطلع في تويتر.
في `index.html` غيّر السطرين:

```html
<meta property="og:image" content="assets/img/share.jpg">
<meta name="twitter:image" content="assets/img/share.jpg">
```

إلى الرابط الكامل، مثلاً:
`https://اسم-حسابك.github.io/valila-lost-phone/assets/img/share.jpg`

## اللي يصير للزائر

- شاشة القفل: «هذا الجوال ضايع… لا تفتح الواتساب ولا الملفات».
- بعد ٢٥ ثانية: رسالة من CEO ڤاليلا.
- بعد **دقيقة**: اتصال من «مدير تسويق ڤاليلا». يرد ← «افتح المتصفح عشان تقدر ترجع الجوال» ← يفتح Safari على صورة العرض والمتجر.
  إذا رفض أو ما رد: يوصله نفس الطلب كرسالة وإشعار.
- بعد دقيقتين ونص: تنبيه البطارية ٥٪.
- الملفات ← «لا تفتح» ← `لا_تفتح.pdf`: Face ID يفشل، ثم رمز الدخول (أول محاولة دايم غلط، الثانية تفتح).

لتجربة الاتصال بسرعة افتح الرابط وفي آخره `#call` (يرن بعد ٣ ثواني من فتح القفل).

## تعديل المحتوى

كل النصوص في `app.js`:
- `CHATS`: محادثات الواتساب.
- `PRODUCTS`: العطور والأسعار في Safari.
- `ROLL`: صور تطبيق الصور.
- `STORE`: رابط صفحة العرض في المتجر.

الأصوات في `assets/audio`: `fahad.mp3` (الفويس في قروب التسويق) و`manager.mp3` (مكالمة مدير التسويق، والنص يظهر على الشاشة مع كلامه).
